## Select, decode and encode

**First-year degree · ages 18+**

A multiplexer chooses an input, a decoder selects an output and a priority encoder turns active inputs into a binary code.

### Your investigation

Write the expected outputs for each input combination. Follow the independent A, B, C and D inputs, then explain the encoder priority when several inputs are high.

### This activity

Use compatible component models or a gate-level circuit. Capture outputs while enumerating data/select inputs.

### Getting started

Open the Simulation tab and press Run. Select a source or component to see its values. Read the labelled signals, then change one quantity at a time. Equal net labels identify connected points.

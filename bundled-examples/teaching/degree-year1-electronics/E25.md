## Plan the controller connections

**First-year degree · ages 18+**

The controller needs power, a reference, input definitions and appropriate output interfaces. This drawing documents connections; it does not run your program.

### Your investigation

Identify the input levels, clock and reset. Plan the software or HDL separately and check load current before connecting an output.

### This activity

Record supplies, connectors, pull resistors and external driver stages. TinyCAD does not program an FPGA, execute firmware or replace the course's digital development environment.

### Getting started

This is a connection-planning drawing. Follow each labelled net, identify the real terminals and add your bench measurements. No simulation is attached.

INPUT0 has a pull-down resistor. Connect the clock/reset labels to the development board. Check output current and add a suitable driver for a real load.

**Explain:** Use an equation, a truth table or a state sequence to justify your prediction. Include units and discuss the model assumptions.

Check the physical layout with your teacher before construction.

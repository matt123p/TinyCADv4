## Conservation in a network

**First-year degree · ages 18+**

Follow each closed current path. At a junction the current entering equals the current leaving; voltage changes around a loop add to zero.

### Your investigation

Measure the marked nodes. Check a junction and a complete loop, stating your sign convention.

### This activity

Solve the same network by two analytical methods and compare each node/current with the numerical solution. Use signed reference arrows.

### Getting started

Open the Simulation tab and press Run. Select a source or component to see its values. Read the labelled signals, then change one quantity at a time. Equal net labels identify connected points.

## Follow the system interfaces

**First-year degree · ages 18+**

A system diagram shows where signals enter, how they are conditioned and where the results are used. Labelled connections describe interfaces; physical and software behaviour need separate evidence.

### Your investigation

Follow each signal from source to destination. Mark the reference, expected voltage range, loading and useful test points. Explain how you would test each stage.

### This activity

Draw supplies, references, sensor connections, driver and receiving equipment, with test points. The full mechanical/process/software system remains outside TinyCAD.

### Getting started

This is a connection-planning drawing. Follow each labelled net, identify the real terminals and add your bench measurements. No simulation is attached.

The transistor is an example output driver. Choose a load and base resistor using the actual sensor voltage and load current.

**Explain:** Use an equation, a truth table or a state sequence to justify your prediction. Include units and discuss the model assumptions.

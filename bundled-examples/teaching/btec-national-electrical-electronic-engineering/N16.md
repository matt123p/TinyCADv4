## An output has limits

**Post-16 · ages 16–19**

Logic outputs have finite drive resistance. Connecting another stage and a capacitive load can change transitions even when the truth table is unchanged.

### Your investigation

Compare input and output transitions. Add a small capacitor at an output and predict its effect. These educational gates do not qualify a particular commercial logic family.

### This activity

Compare loaded output and input thresholds using compatible models. Capture propagation delay only if the models represent it. Ideal Boolean behaviour cannot establish real-family specifications.

### Getting started

Open the Simulation tab and press Run. Select a source or component to see its values. Read the labelled signals, then change one quantity at a time. Equal net labels identify connected points.



**Explain:** Use an equation, a truth table or a state sequence to justify your prediction. Include units and discuss the model assumptions.

The model predicts electrical behaviour; it does not replace real practical measurements.

## A temperature-dependent input

**First-year degree · ages 18+**

The NTC resistance falls as its entered temperature rises. The divider converts that resistance change into a voltage change.

### Your investigation

Predict which way OUT moves as Temperature changes. The entered temperature is a model input, not a simulated heater.

### This activity

Enter measured sensor voltage/resistance data and compare interface output for different loading. The physical calibration is obtained independently, not generated by fitting the same simulation.

### Getting started

Open the Simulation tab and press Run. Select a source or component to see its values. Read the labelled signals, then change one quantity at a time. Equal net labels identify connected points.



**Explain:** Use an equation, a truth table or a state sequence to justify your prediction. Include units and discuss the model assumptions.

The model predicts electrical behaviour; it does not replace real practical measurements.

## Feedback sets the gain

**Post-16 · ages 16–19**

The input signal reaches the inverting input through a resistor. A feedback resistor returns part of the output to the same node.

### Your investigation

Predict the signed gain from the resistor ratio. Check amplitude, inversion and output clipping.

### This activity

Choose two resistor ratios, apply a small sine and compare signed gain, phase and summing-node voltage. Repeat at larger input amplitude to expose saturation if the model supports it.

### Getting started

Open the Simulation tab and press Run. Select a source or component to see its values. Read the labelled signals, then change one quantity at a time. Equal net labels identify connected points.



**Explain:** Use an equation, a truth table or a state sequence to justify your prediction. Include units and discuss the model assumptions.

The model predicts electrical behaviour; it does not replace real practical measurements.

## Plan the controller connections

**BTEC First · ages 14–16**

The controller needs power, a reference, input definitions and appropriate output interfaces. This drawing documents connections; it does not run your program.

### Your investigation

Identify the input levels, clock and reset. Plan the software or HDL separately and check load current before connecting an output.

### This activity

Document input switch, controller pins, supplies and display connections. Firmware execution, flowchart programming and seven-segment decoding are not ready-made TinyCAD workflows. Electrical interface stages can be tested separately.

### Getting started

This is a connection-planning drawing. Follow each labelled net, identify the real terminals and add your bench measurements. No simulation is attached.

Each display segment A–G has its own 330-ohm current-limiting resistor. COM and the unused decimal point return to the reference. OUT6 uses GPIO1; OUT0–OUT5 use GPIO2–GPIO7. Write and test the segment lookup table in the separate programming environment. INPUT0 has a pull-down resistor. Connect the clock/reset labels to the development board. Check output current and add a suitable driver for a real load.

# About dialog license files

Parcel writes `licenses/index.json` and the individual text files into each renderer output. The browser inventory comes from Parcel's bundle graph. Desktop builds also include installed production npm dependencies because Electron Builder packages them separately from the renderer. License and notice files from the installed packages take precedence as source material. The dialog loads those files locally on demand.

`upstream.json` supplies missing npm notices and additional terms for subcomponents. Its version-specific entries should be checked when those packages change. DOMPurify is redistributed under its Apache 2.0 option. Type-Fest is redistributed under its CC0 option. Grants such as 0BSD without a notice condition do not get an entry.

Sources for the supplemental files include the [Fluent System Icons license](https://github.com/microsoft/fluentui-system-icons/blob/e940effc000de2521ce4cf47ef45499e921c66dc/LICENSE), the [Embla Carousel license](https://github.com/davidjerleke/embla-carousel/blob/0fe65834136f1aa35e4c1a4a477e5ccb4bb5ee54/LICENSE), the [Rollup release license](https://github.com/rollup/rollup/blob/v4.53.3/LICENSE.md), the [canvas release license](https://github.com/Brooooooklyn/canvas/blob/db337893b9b53483050ca7b24c6d306e4da06741/LICENSE), the [Skia license](https://github.com/google/skia/blob/main/LICENSE), and the [Liberation Fonts 2.1.5 license](https://github.com/liberationfonts/liberation-fonts/blob/2.1.5/LICENSE). The Adobe font metrics terms accompany PDFKit's bundled AFM files and are reproduced in the [Apache PDFBox license inventory](https://github.com/apache/pdfbox/blob/trunk/LICENSE.txt). The older Brotli, DFA and SWC helper notices use the MIT grants declared by their published package metadata. Brotli also retains the Apache 2.0 terms for the Google codec code.

The ngspice entry uses a copy of the pinned release's upstream `COPYING` file, so the notice is available before the engine is staged. The supplemental notices come from `src/maths/sparse`, `src/maths/KLU`, `src/frontend/numparam` and `src/xspice/icm/table` in that release. The desktop picker has a separate GPL notice for its XSPICE table models. The [Emscripten license](https://github.com/emscripten-core/emscripten/blob/4.0.23/LICENSE) and [musl notices](https://github.com/emscripten-core/emscripten/blob/4.0.23/system/lib/libc/musl/COPYRIGHT) cover the embedded WebAssembly runtime code.

The picker groups Fluent UI and React packages into one entry per project, with a package list and each distinct upstream notice. The SQLite entry identifies the public-domain SQLite engine and displays the MIT notice for the bundled sql.js wrapper.

Electron and Chromium license files are copied from the exact Electron archive being packaged. Chromium's original credits document opens from its entry in the About dialog.

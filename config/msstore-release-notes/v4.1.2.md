### What's fixed in v4.1.2

- Direct printing on Windows is restored. Print Preview saves your printer and paper settings, and Advanced Print opens the selected sheets as a PDF. Page Size now supports millimetres and inches.
- Newly placed standard library symbols show their editable names by default, without duplicate captions.

### What's new in TinyCAD v4.1

- Run SPICE and XSPICE simulations locally with virtual instruments. Use Circuit Explorer to tune circuits, sweep parameters and study component tolerances. Get started with bundled models, tutorials and runnable examples.
- Use desktop AI chat to work on schematics and symbols. Import images, use PDFs as references, and arrange schematics with automatic layout and wire tidy-up.

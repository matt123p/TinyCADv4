# Circuit Inspector

Inspect the current schematic, keep notes in a design or symbol, and try a plugin component library.

- **Left panel:** choose Circuit Inspector for a live summary.
- **Bottom panel:** choose Design notes; notes are saved in the `.dsn` file.
- **Symbol editor:** the Plugin metadata tab stores notes on the symbol definition.
- **Tools / toolbar:** Inspect circuit opens a connectivity report in a main tab.
- **Component library:** choose Example components in the left panel, then place the two-pin component.

This example works in the browser and Electron. No external network service is used.

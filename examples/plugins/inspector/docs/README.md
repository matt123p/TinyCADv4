# Circuit Inspector documentation

## Inspecting a design

Choose **Circuit Inspector** in the left panel or **Inspect circuit** in the toolbar. The main report includes connectivity generated by TinyCAD.

## Design notes

Choose **Design notes** in the bottom panel, enter text, and click **Save notes**. Save the design normally to write those notes to disk. Use Undo to reverse a notes change.

Notes remain in the file when this plugin is disabled or uninstalled. The Context panel remains available alongside plugin choices.

## Components

Choose **Example components** in the left panel. Place a component to embed its definition in your design. The component remains usable after the plugin is removed.

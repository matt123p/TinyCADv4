# Project Home

Open multiple circuit files and switch between them without sharing undo history or save state.

Choose **Project Home** in the plugin toolbar or View menu. Use **New design**, **Open design**, and each file's Open/Save/Close buttons. You can also choose **Project files** in the left panel.

The application keeps document tabs available if the plugin is disabled. Save All reports failures per file.
